# 未接入的进程绑定读取实验

此文件夹不纳入产品构建。管道创建复用祖先 `9318052` 的当前用户受保护 DACL、首实例标志和拒远程标志。读取器使用调用方持有的进程句柄和内核客户端 PID 核对，复制文件句柄，比较调用方事先捕获的文件卷/文件 ID/创建时间线索，读取最多 256 KiB 并验证 SHA-256 和 JSON 原请求 ID；每个读取器只消费一次。

Windows 独立子进程测试检查 DACL、首实例冲突、正确传输、内容漂移、同内容路径替换、进程退出、错误进程、请求身份漂移与重放拒绝。进程退出检查不构成原子存活保证；同用户注入与管理员不属于拟定信道保证。远程及异用户实际连接未验证。

这仍不是完整可信服务端：构造器接收的进程句柄必须由可信自启动 owner 持有，但本实验没有该 owner、生命周期管理、超时/取消与附着服务排除机制。文件身份和摘要须由可信 owner 事先获取，本代码不证明其来源；接收参数也尚未绑定管道由本工厂创建的事实。共享文件句柄不保证读取后不可写，也未覆盖恶意并发写入或替换竞态。不得接入宿主、注册能力或视为完成权限和原回执链路。
