# 未接入的进程绑定读取实验

此文件夹不纳入产品构建。`ProcessBoundReceiver` 仅尝试验证调用者提供的保活进程句柄与已连接管道的客户端 PID，再从该进程复制句柄，对最多 256 KiB 读取的字节验证 SHA-256 和 JSON 原请求 ID；任何调用都会消耗对象。当前只有受控同进程 peer 验证无效调用及重复消费拒绝，Framework C# 编译通过。

这不是完整管道服务端：没有创建 current-user DACL、first-instance、拒远程管道，没有自启动 owner 来证明进程句柄来源或拒绝附着进程，也没有独立进程端到端测试。尚未证明文件句柄固定身份、同内容替换拒绝、读取时并发修改和进程退出行为；提供的共享文件句柄并不自动保证不可写。不得将这些前提视为已满足，不可接入宿主或注册能力。远程与其他用户权限、真实 Revit、同用户注入和管理员对抗均未验证；后两者也不属于拟定信道保证。
