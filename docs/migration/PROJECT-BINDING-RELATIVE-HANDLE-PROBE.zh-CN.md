# Windows 相对目录句柄探针（研究）

2026-11-07：新增独立只读 NtCreateFile 探针。保留已打开的根目录句柄，以 OBJECT_ATTRIBUTES.RootDirectory 相对打开单个子目录；测试在根句柄打开后真实移动根目录并在旧路径创建替代目录，结果指向原对象的新路径，1/1。既有目录 pin 实验复测 3/3，证实锁定父级不足以防止子目录移动，且已 pin 的 scope 仍可被重命名。

这不是竞态修复：探针没有实现创建锁、原子记录、归档、原回执恢复、异常或并发操作，也没有检查可信根身份、reparse point 全链路、权限或断电持久性。未接入研究 owner 或服务；项目参数门禁保持默认关闭。下一步需设计并实现相对句柄下整个生命周期，包括安全创建和句柄归档，并验证 ACL 与失败关闭；不能使用本探针作为生产安全依据。没有操作 Revit、41874 或模型。
