# AEC 材料、碰撞候选与基础建模接入

2026 年 11 月 7 日。本批接入 6 项。原 50 项未接入能力在上一批后余 47 项，本批后余 41 项。独立候选工作区目录为 71 项，其中 43 项只读。AEC 对照按固定的 103 项清单统计。[工具台账](AEC-103-CROSSWALK.zh-CN.md)

| 工具 | 执行范围 |
| --- | --- |
| `revit_calculate_material_quantities` | 按当前文档的类别扫描实例，按材料 ID 汇总非涂料体积。用量为立方英尺，名称和实例计数按需返回。 |
| `revit_check_clashes` | 按两个类别和英尺容差比较扩张后的轴对齐包围盒。最多 50,000 对，同类去重，结果列出缺框数并标记实体相交未测试。 |
| `revit_create_level` | 按名称和项目高程创建标高，单位为 mm，回读项目高程。 |
| `revit_create_grid` | 按名称和两个等高端点创建直线轴网，单位为 mm，回读实际曲线端点。 |
| `revit_pin_element`、`revit_unpin_element` | 按当前文档中实例的精确 ElementId 固定或取消固定，回读前后状态。 |

两个查询的类别输入接受内建类别枚举和已有别名。受控扫描完成后按页返回，超预算或无效数据时失败。四个写入要求宿主 0.8.9 的具名能力，沿用文档身份、权限、默认回滚、事务和原回执核对。模型效果有疑问时保留原请求供核查。

聊天 `@` 提供完整注册工具列表，上下键可滚动到所选项，回车插入工具引用。聊天和命令栏共用英文全名、词段、首字母和中文名称匹配，例如 `cmq`、`cc` 和 `ggm`。Code Mode 的 `elements` 支持分页发现这 6 项，按准确名称可取完整契约。
