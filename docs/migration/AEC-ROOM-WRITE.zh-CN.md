# 创建房间：隔离实现边界

`revit_create_room` 接受当前文档标高 ID、Revit 内部坐标 XY（毫米）和可选名称、编号；不接受阶段输入。`NewRoom(Level, UV)` 的阶段由 Revit 决定，回执读取实际阶段 ID；不可用时返回 null。面积采用 Revit 内部平方英尺，未封闭或无有效面积时失败并回滚；体积采用内部立方英尺，未计算或无有效值返回 null。位置和标高在创建后与内层事务提交后重新核对；外层事务决定默认回滚或提交，不保存文档。

编号预检保守拒绝当前文档中已使用的编号。对最终阶段的 `GetRoomAtPoint` 正向发现房间时拒绝，空结果并不能证明没有其他阶段或重叠的房间。返回的 ID 在回滚预览后不代表模型中存在。真实 Revit 中阶段、房间边界、面积/体积设置、事务及 WebView 交互仍需验证。
