# AEC 图纸域与工作区检索验收

日期为 2026 年 11 月 7 日。AEC 台账新增两个候选映射，原 50 项未接入能力还剩 48 项。当前工作区源码目录为 64 项，其中 40 项只读。

- `revit_get_revision_sequences` 分页读取修订实例及签发状态，按修订序号与稳定 ID 排列。
- `revit_get_schedule_data` 读取指定明细表的正文显示值，默认最多 50 行、20 列。行列可单独分页，单页最多 2,000 格。新操作需要宿主明确发布各自的原子只读能力。
- `buildx_model_operation_schema` 支持按领域返回紧凑分页，再按准确名称返回完整契约。写入口发布工具名和参数对象，执行端继续按完整契约校验。含终端时的动态注册分别为 8,570 和 8,619 字节。原生只读 MCP 仍按现有协议注册。
- 聊天框从实际工作区目录生成 `@` 候选，支持中文标签、英文名称、词段和首字母。`@gsd` 可定位明细表查询。Enter 或点击只插入工具引用。命令栏继续使用具名接口和同一回执链。

## 验收记录

Node 契约、队列、权限和真实 Codex 构造器回归 88 项通过。工作区 `@`、命令栏及终端界面受控测试 28 项通过，包含点击「图纸修订」的查询按钮后只发送一次原接口请求。C# 受控宿主 102 项、图纸域受控生产者及 36 份 C# 的 Revit 2024 API 引用编译通过。

独立 Revit 启动在候选宿主初始化前遇到 Autodesk 许可管理器错误。真实 Codex 与合成 Revit 授权夹具的混合对照确认客户端已连接，终端开关及对话请求已接收。首轮未取得终端原请求 ID，保持未确认。本轮没有真实 Revit WebView、命令栏点击的实机回执或模型写入。

独立实机复测先确认候选服务、模型副本和原生队列使用同一安装标识。工具逻辑通过候选端口查询，检查字段、来源文档、回执 ID 与只读状态。界面验收用 Computer Use 操作同一候选，观察 `@` 检索、命令按钮和原回执显示。按请求 ID 对照两份证据。每小时推进任务以台账余项和最近验证结果为输入。
