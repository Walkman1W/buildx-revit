# 批量创建图纸：原生受限契约

`revit_batch_create_sheets_from_csv` 接受 1–50 条已经解析好的 `sheets` 行，每行包括图纸名称、编号和可选的精确图框类型 ID。省略图框 ID 创建占位图纸；宿主不读取 CSV 路径或任意文件。命令栏提供逐行输入。先检查全部编号及图框类型，再在同一事务中创建；任一失败整批回滚。生成与内层事务提交后，逐张回查 ElementId、UniqueId、名称、编号、占位状态和图框实例类型。默认预览回滚，提交不保存模型；未知结果保留原回执，不自动重放。

原 AEC provider 映射 CSV 路径和图框名称，但 bridge 实际读取 sheet 行并按行捕获异常、允许部分成功；两者契约存在差异。本实现使用显式行和精确类型 ID，不负责读取或解析 CSV 文件，也不沿用部分成功。真实 Revit 图框、工作共享、事务和内嵌 WebView 尚待验收。
