# 原生结构柱受限能力

`revit_create_column` 接受项目内结构柱类型、底部和顶部标高的精确 ID，以及底部点的 Revit 内部坐标（毫米）。仅接受 `TwoLevelsBased` 非宿主结构柱，顶部标高必须高于底部，基准点 Z 必须等于底部项目高程，底部和顶部偏移为零。创建后和内层事务提交后回读实例、类型、标高、结构类型、垂直状态、点、四项约束和包围盒；包围盒顶部和底部必须在目标高程 1 mm 内。不能满足这些条件的族或模型会失败并回滚。

默认回滚预览；提交保留未保存的模型变更。包围盒检查不证明结构承载力、构件连接或没有碰撞。回执包含两标高项目高程和高度，但其数值只是本次回读事实。真实 Revit 中族类型、包围盒、约束更新、事务及 WebView 仍需验收，本次没有加载 DLL 或写入模型。
