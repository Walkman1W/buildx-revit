# 图纸批量重编号的原生受限契约

`revit_renumber_sheets` 要求显式提供 1–50 行 `sheet_id`、`expected_number` 和 `new_number`。它检查图纸当前身份和原编号，拒绝重复图纸、重复目标以及未选图纸占用的目标编号；整个项目图纸编号不可读取或存在歧义时拒绝。交换与循环先使用与全部当前编号和目标编号均不冲突的临时编号，再一次性写入目标；失败由事务回滚。临时编号不作为最终结果返回。

每行回执保留图纸 ID、原始 UniqueId、原编号和最终编号；重生成和内层事务提交后均重新读取，并检查全局编号。外层事务默认回滚预览，提交不保存模型。原回执不匹配时结果保持未知，不自动重发。

上游 AEC provider 暴露 prefix/start_number，而其 bridge 实际读取 sheets/new_sheet_number 并逐行捕获错误、允许部分成功；二者的契约不一致。本实现采用显式清单、原态守卫和整批原子语义，没有继承 prefix/start_number 的自动编号或部分成功行为。真实 Revit 对编号、工作共享、事务及 WebView 仍需验收。
