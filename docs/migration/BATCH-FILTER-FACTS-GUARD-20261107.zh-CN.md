# 批量参数筛选写入：事实比较研究切片

基于 `5cdcc2b`，从私有研究分支 `origin/codex/aec-filter-research-20261107` 移植未注册的 `BatchFilterFactsGuard`。该原语冻结完整有界预览的摘要，比较宿主会话、文档对象、执行线程、目标值及整份预览；它不授予审批、执行、队列认领或回执权限，也没有产品调用者。

新增受控 peer 覆盖跨线程及冻结后原始对象变化，共 14/14；现有预览及新增写入口未注册边界 Node 合组 9/9。两者均为隔离测试，不是真实 Revit、审批界面或生产队列验证。

`revit_batch_set_parameters_by_filter` 继续关闭且不在目录或宿主路由中。研究分支发现普通文件和 Node 模块加载不能证明已审阅请求与执行进程绑定；现有内存防重不能覆盖崩溃及重启，回执身份和持久化也未闭环。不能把事实摘要当作可信人类确认或持久防重。接入前需完成受信进程与请求对象绑定、原生完整逐次确认、持久认领和原回执及未知结果不重放，再验证完整事务和故障恢复。真实 Revit、WebView、41874、模型写入均未操作或验证。

## 宿主准备凭证研究（2026-11-07）

新增未注册的 `BatchFilterPreparationBook`，以同一宿主内单次消费、120 秒单调时钟期限和 128 项容量，将文档对象、完整事实摘要和目标值绑定。失败也消费票据；宿主重启后旧票据无法使用。受控 C# peers 10/10，写入口关闭边界 Node 1/1；没有真实宿主或模型执行。此原语尚无生产调用者，普通对象仍可构造所谓预览，只有宿主直接调用生产者并封装后才能作为准备事实；票据不等于人类审批、原请求持久防重或回执。

类型参数机制可作为相同威胁模型的实现基线：面板可信逐次决定与宿主准备分别绑定同一规范请求；宿主重读并验证完整成员及原值，消费令牌后执行，原请求回执负责未知结果核对。现有类型令牌是进程内状态，不证明跨重启持久幂等。批量入口还缺真实宿主 prepare 路由、不可伪造的 Node 审阅绑定、逐项写入与阶段回读、事务及回执集成，持久认领和故障恢复也尚未实现；因此继续关闭，不计入已接入工具。

## 写入阶段闭合候选（2026-11-07）

新增未注册 `BatchFilterWritePhases` 与 `BatchFilterWriteCoordinator`：完整冻结原快照，逐项校验筛选、排序身份、UniqueId、参数元数据、原值与目标值；在模拟事务中于每次写前后、再生后及内层提交后重新读取并核对，失败要求外层组回滚。C# 受控 peers 18/18、关闭边界 1/1；首次编译因检查脚本漏传协调器而失败，修正后通过。测试中的读取、写入和事务均为回调替身，尚未接 Revit producer 或真实事务、宿主路由、可信面板及原回执；外层回滚失败与持久防重仍未验证，不得据此开放写入口。

## 实际 producer 与事务 API 候选（2026-11-07）

新增未注册 `ExecuteBatchFilterCandidate`：以现有 `PreviewBatchParameterFilter` 重捕，协调器逐项核对后调用实例参数 owner，在 `Transaction` 内执行并由 `TransactionGroup` 决定提交或回滚，不保存模型。实际 producer 与事务 API 替身合组 6/6，覆盖提交、回滚、再生漂移和身份漂移；四个候选 C# 文件以本机 Revit 2024 `RevitAPI.dll` 引用编译成功，部分其他 owner 方法为编译替身，不能等同完整产品编译。编译初次使用相对路径失败，绝对路径复验通过。

候选目前无生产调用者，接受的 snapshot 并非可信审批；没有宿主 prepare、人工决策、原回执和跨重启防重，也没有真实 Revit 事务或故障恢复验证。每项前后均重扫筛选集，最多 50 项、每次扫描上限 20,000；尚无整批耗时上限或性能实测，须评估回调占用。回滚异常仍需宿主记录未知状态。入口继续关闭。
