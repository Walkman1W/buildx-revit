# 删除操作审批 owner：独立准备切片

本切片没有注册删除命令，也不修改现有权限或 Revit 宿主。它提供独立的进程内 owner：只能通过由未来可信传输层注入的 `consumeVerifiedPreview` 消费一次性原回执；要求明确回滚成功、完整且有界的级联 ID/UniqueId 列表、目标身份、宿主会话、原请求 ID 和有效期。owner 对冻结的文档、请求、预览、原生 token 计算 digest；待可信界面调用的决定对象和后续许可均为进程内单次能力，拒绝伪造、过期和不匹配。

受控测试使用模拟传输 verifier，证明本模块的校验和一次性绑定；不证明该 verifier 已存在，也不证明真实 Revit 回滚、级联清单完整、用户决策来自界面或模型可以安全删除。`issueDecision` 必须仅由可信面板的人类决定路径调用；将模块接到普通工具或把客户端自报的确认传入它是不安全的。

后续须实现并验证：原生回滚预览与有效的单次宿主许可；传输层只接受原请求回执并核验回滚、文档身份和完整影响事实；可信审批 UI 展示实际级联后在所有模式强制逐次确认；封闭动态、手动、原始 dispatcher 的绕行；提交时在宿主内重新核对各 ID/UniqueId，`Document.Delete` 返回集合必须与确认集完全相等，否则事务组回滚；超时或清理未知保留原回执，不自动重放。上述闭环完成前不得登记删除能力。
