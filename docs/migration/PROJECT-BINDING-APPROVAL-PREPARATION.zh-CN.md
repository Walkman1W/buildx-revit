本切片仅提供进程内审批准备原语，未注册创建或绑定命令，未接入生产界面或宿主，也不调用 Revit。调用方必须提供未来实现的可信原回执单次消费验证器；模拟验证器不是可信实现。它绑定项目路径、标题、宿主会话、定义 GUID/ID/数据类型、类别、完整有界实例身份、原请求 ID 与快照；显示审阅副本，决定和许可为进程内一次性能力，失配和过期失败关闭。未来实例也会受到绑定影响。

共享队列的来源身份和保密性尚未建立，当前 WebView 没有经验证的私有审批信道。预览指纹、请求 ID 或客户端自报布尔值均不构成人类授权；不得把此原语接到生产入口。还须实现受信原始回执核验与消费、明确展示完整影响的逐次人类决定、宿主文档对象与会话身份、受限信道及防重，宿主事务内重新采集并比对影响、提交后核验绑定与事务结果，未知结果仅核对原回执且不重放。实际 Revit 中已有未绑定定义是否可插入仍未验证。

验证范围：Node 受控测试使用模拟 verifier，覆盖原回执缺失、完整性与身份不符、重复实例、过期、审阅隔离、决定/许可一次性和失配烧毁；不验证真实信道、真实用户、事务或模型。运行 `node --test lib/project-binding-approval-owner.test.mjs`。
