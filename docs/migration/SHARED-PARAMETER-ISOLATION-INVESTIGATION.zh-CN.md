# 共享参数隔离候选调查

AEC 本机基线 `BridgeCommandFactory.ExecuteCreateSharedParameter` 读取名称、类型、组和类别后抛出 `NotImplementedException`；不能把它描述为已有可工作的语义。本候选没有注册工具；真实 Revit 定义和用户文件均未创建。

Revit 2024 本机 API 文档指出 `Application.SharedParametersFilename` 是应用级可读写路径，`OpenSharedParameterFile()` 使用该路径打开磁盘定义文件，应用一次使用一个共享参数文件。`ExternalDefinitionCreationOptions` 接受名称和 `ForgeTypeId`，GUID 必须显式设置，否则会随机生成。定义文件是磁盘副作用，不能假设文档事务回滚会恢复文件。

尚未建立可靠的隔离创建链路：临时设置路径后，读取当前值再恢复原值并不是原子比较交换；若其他插件或用户在检查和恢复之间更改该设置，可能覆盖其变化。即使检测到漂移后拒绝恢复，也不能声称应用状态已恢复。还需解决隔离目录身份和重解析点、独占新建、定义写入及精确读取、异常清理、文件身份漂移，以及可信用户文件授权和原请求回执。必须先证明可安全协调实际宿主上的全局设置，或找到不修改该设置的受支持 API；否则不能公开登记。

`tools/shared-parameter-prototype` 现有未注册、未纳入正式构建的实验原型：使用 CreateNew 创建新文件，记录请求组、名称、GUID、数据类型、原设置、目标路径、创建时间线索、阶段和恢复结果；异常后保留部分文件，不覆盖已有文件。受控替身覆盖成功、冲突、部分写入失败、并发设置变化、重入及非法路径，共 7 项通过；该原型和 Revit 2024 API 适配器单独引用真实 API 编译通过。

文件路径加创建时间仅是线索，不是可靠文件身份；代码未防重解析点或路径替换。空文件能否由真实 Revit 打开、定义是否持久化和读取均未验证。适配器中的 check-then-set 和恢复不具原子性，不能保证不覆盖并发变化；恢复异常或漂移即使定义已写入也不表示安全成功。原型不具真实用户文件授权和原回执，不得用于生产或注册工具。本次没有操作真实 Revit、模型或用户共享参数文件。
