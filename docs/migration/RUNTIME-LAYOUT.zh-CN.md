# 独立运行路径与数据布局

日期：2026 年 11 月 5 日。配置与源码已实现并通过隔离验证，未修改任何已安装配置、用户历史、旧项目、Revit 或既有服务。

## 唯一布局入口

Node 使用 `lib/buildx-paths.mjs`；Revit 使用从 DLL 安装位置读取同一 `buildx-installation.json` 的 `BuildXInstallation`。不再保留旧开发根或个人 Node 缓存例外。新版安装配置 schema 2 明确 `installationId`、Node/Python/Codex 可执行文件和独立 `dataRoot`，程序根由实际入口/DLL 位置推导。

| 内容 | schema 2 位置 | 归属 |
| --- | --- | --- |
| 网页、MCP、模块、插件、公告 | 程序根 | 版本化程序资源 |
| 可选私有执行资源 | 程序根/private-runtime | 只容纳另行核实来源的运行程序；本轮不复制研究资源 |
| 服务日志与状态 | dataRoot/runtime | 运行数据 |
| 聊天、附件、资料库引用、访问权限状态 | dataRoot/runtime-history | 持久用户数据与独占锁 |
| 项目资料历史 | dataRoot/project-history | 持久用户数据；新版不被继承环境变量改向 |
| 命令库、队列、原回执、族作业、截图 | dataRoot/workbench | 模型工作台数据与原请求 owner |
| WebView2 浏览器数据 | dataRoot/WebView2 | 当前安装的浏览器数据；不随包复制 |

`server.mjs` 分别注入程序与数据根；网页不从数据目录提供，截图不从程序目录接纳。生命周期、访问策略、查询和命令库都使用该布局；MCP 子进程独立读取同一配置，避免只改主进程而遗漏工具队列。程序资源、数据所有权标记和访问策略文件受文件工具保护。

schema 1 保持原程序目录内的数据位置，原 WebView2 位置也保留；不因格式升级静默搬移历史或未知回执。无配置的纯源码/测试入口仍可使用自身相对目录；Revit 插件加载器无配置则明确拒绝，不能猜旧开发目录。迁移、升级和数据恢复尚未实现或验收。

Node 配置读取拒绝未知/重复字段、超预算、非法编码、相对/非规范路径、段末点/空格、程序与数据父子重叠，以及已存在路径链上的链接；有界读取期间文件消失或身份变化不会回落源码模式。C# 与 Node 的 schema 2 启动前都必须核对 `buildx-data-owner.json` 的普通文件身份、格式、预算及精确安装 ID，缺失或错配时不创建队列。安装计划仅接纳新的独立数据目录并创建该标记；复制时验证自建目录链，检测替换则保留现场、不沿明显链接继续写入。portable JavaScript 仍不能消除所有操作系统级竞态。

## 执行资源和保留项

ScriptRunner 编译器改为 `private-runtime/script-compiler/csc.exe`，不再探索 `_reference`。缺编译器时在写脚本目录和执行模型代码前明确失败。Argus 适配器仍有真实业务消费者，源码保留，资源入口改为程序的 `private-runtime/argus`，不再从用户数据目录加载程序集。恢复程序集、推理程序和模型均不进入候选；相关功能仍受缺项与分发阻塞约束。

Node/Python 由安装配置明确选择，Codex 始终使用用户已有程序，不复制或升级。Python 自动发现已取消 Codex 私有缓存兜底，只接受明确配置或可核实的 PATH 程序；源码模式允许操作者显式选择已有路径，发现并不等于可用性验收。
