# AEC 墙上放窗迁移与 Codex 验证

2026 年 11 月 7 日。新增 `revit_place_window`，并合入文字注释候选。AEC 原 50 项未接入能力余 32 项。候选目录为 80 项，其中 43 项只读。

每次指定窗类型、直墙、标高的精确 ElementId 和 Revit 内部坐标位置，位置单位为毫米。可选方向为水平、垂直于墙的无量纲单位向量。执行端核对窗族类别和可宿主类型、墙的几何及分组、位置和方向。再生及内层提交后重新读取宿主、类型、标高、位置、朝向和可用尺寸。当前支持垂直、非组内的直线基本墙；异形墙和其他族放置方式需要后续验证。

写入沿用具名宿主能力、文档绑定、权限和原回执，默认预览回滚。成功应用且来源身份可核对时，安全整数元素 ID 能通过本次请求 ID 接续视觉检查。回滚的元素 ID 无法作为检查来源。字符串形式或超过 JavaScript 安全整数的 ID 暂不进入视觉来源登记。

- 真实 Codex app-server 和模型使用合成文档、合成构件 ID，在同一轮依次调用 `buildx_model_operation_schema` 和 `buildx_model_operation`。BuildX 权限 owner 将模式设为回滚，合成宿主接收一次调用，回执为 `committed=false`。Revit 未参与本次调用。
- 真实 Edge 在隔离本机面板验证 `@pw` 搜索插入。命令栏以回滚权限发送一次请求，HTTP 202，界面显示完成，合成命令处理器回传 `committed=false`。该路径使用模拟文档和处理器。
- 窗口生产 C# 和事务方法用受控 Revit peers 验证，包括错误族类别、宿主、位置、朝向及提交后身份漂移。合并后的文字注释和既有视图生产者也复验。
- 合并后 Node 合组 123/123、两份参数写入生产者合组 215/215、受控宿主 105/105 通过。原视觉检查测试中的过时夹具已按当前显式恢复契约调整，创建窗后的检查来源另有针对性受控验证。
