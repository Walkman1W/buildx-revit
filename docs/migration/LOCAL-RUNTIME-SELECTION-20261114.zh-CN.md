# 本地 Codex 运行时选择一致性

## 变更与调用链

- detectLocalRuntimes → resolveCodexExecutable。
- CodexClientCore 默认依赖 resolveLocalRuntimes → resolveCodexExecutable，在 spawn 之前解析。
- 已安装服务 resolveInstallationRuntimes 继续注入安装配置 codexExecutable / pythonExecutable；显式已选路径优先于 PATH，不修改已有安装配置。
- 删除 strictWrapper 分歧：前置 npm wrapper 与后续 exe / 桌面 exe 同时存在时，预检、运行时统一拒绝猜选。仅明确设置 BUILDX_CODEX_EXE 可消除歧义。
- PATH 原有顺序语义保持：优先出现实际 exe 时继续选该 exe；无 wrapper 且唯一桌面候选继续可用；多个桌面候选及失效显式路径拒绝。

## 使用方式

源码启动环境可由操作者将 BUILDX_CODEX_EXE 设为自己确认的现有 codex.exe 绝对路径，然后重新启动该源码服务。不要填 codex.cmd / codex.ps1，也不要复制他人的登录凭据。已安装服务以安装配置为准，本轮不改配置、不重启。遇到失效路径须重新确认真实文件，不能静默切到另一版本。本轮未代用户执行选择。
