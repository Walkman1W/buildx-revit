# AEC 高频能力批次：范围与验证

更新日期：2026 年 11 月 7 日。此记录描述源码和隔离候选，不表示已安装或已加载到真实 Revit。

## 范围

开始时台账有 31 个没有具名入口的 AEC 名称；本批新增 22 个具名候选，余 9 个无具名入口。另有 9 个高权限项目维持暂缓。本批完成的是下述可核实子集，不宣称所有原 AEC 输入、自动搜索与文件副作用已经迁移：

- 建模：房间、直梁、竖直结构柱、独立基础、矩形平屋顶、模型组创建/解组/转换、点式实例镜像复制，以及明确实例的单个换型和批量族类型替换。
- 图纸和标注：空明细表、空白图纸复制、按明确旧号批量重编号、按已解析行批量创建图纸、两个本地平面面稳定参照之间的线性尺寸、唯一图框实例参数。
- 材料和选择：图形材料创建、实例材质参数写入、按 ElementId 或 UniqueId 设置界面选择。
- 变更事件：显式建立完整有界基线，按固定 token 和版本分页读取观察到的增删改；这是会话事件而非净差异。上限为 50,000 个基线元素、5,000 个事件、每页 100 条；事件连续性或文档身份不可信时拒绝结果。多文档及身份包装变化可能触发保守失效。

另新增两个 BuildX 自有只读工具，不计作 AEC 创建或写入工具，也不授予写入权限：`revit_preview_batch_parameter_filter` 按准确类别、可选类型及标高、参数 ID 返回完整的实例 ID/UniqueId 与参数内部原值，最多扫描 20,000 项和匹配 50 项，超限整批拒绝；`revit_preview_project_parameter_binding` 核对文档中已存在但未绑定的共享定义和指定类别的现有实例，最多完整扫描 500 个匹配实例，默认每页 50 项，每页重捕并用绑定宿主与全部影响事实的指纹拒绝漂移。[项目绑定预览范围](PROJECT-INSTANCE-BINDING-PREPARATION.md)

具名候选的主要限制和未覆盖项逐行列在 [AEC 103 项对照](AEC-103-CROSSWALK.zh-CN.md)。特别是：批量图纸输入已解析行而不是 CSV 文件路径；UniqueId 选择不缩放且缺失项整批拒绝；AEC 的图框工具源码实际写图纸参数，本批是指定图框实例参数；类型按明确 ID 而不按名称全模型筛选。稳定参照尚缺通用提取入口。界面选择不能通过模型事务回滚，所有权限模式均逐次确认。

所有新增模型事务维持具名能力门禁、源文档和宿主身份、参数预检、回读、原请求回执与未知不自动重放；默认 rollback，commit 不保存模型。图框参数全批预检前态后复用现有实例参数 setter 和回读。组转换复用组创建的同一个宿主实现。权限策略本身没有被放宽。

## 隔离验证

- 本机真实 Codex app-server 和模型，配合独立合成工作区、合成宿主与回执，分三轮验证 21 个本批入口；每项先请求完整契约，再按给定参数提交一次。19 个事务请求为 rollback，2 个 UI 选择使用合成确认，无自动重试；这些不是真实 Revit 回执。
- 真实 Edge 对独立临时 HTTP 服务验证屋顶及 UniqueId 选择的 `@` 查找、原生表单和各一次模拟请求；选择未确认前没有提交。另验证快照 `@`、状态、启动和分页表单，三个请求均由合成宿主应答。服务、Codex 和模型回执均为夹具，未访问运行中的 41874。
- 真实生产 C# 提取到受控 Revit API peers：合组 152 条、选择 14 条和放窗 9 条通过。检查包括后提交漂移、不同身份、筛选前拒绝和模拟事务失败；不等于 Autodesk 运行时行为。
- 增量目录、字段和 `@` 界面 Node 合组 88/88；权限 owner 23/23，真实隔离 HTTP 在 automatic 模式验证选择操作未确认时拒绝。参数、类型参数、材质和图框的生产 C# 受控 peer 回归合组 217/217。跨目录、权限和回执合组初次为 244/245，唯一失败是生成器为唯一 ID 数组生成重复样本；修复生成器并保持原约束后，合入快照后的稳定源码串行合组 246/246，覆盖原有契约与权限。快照 MCP 回执修正后另有专项 12/12。
- 快照恢复修正后受控 C# 生命周期 46/46、事件桥接 23/23；连续性失效须显式 `start` 并使旧 token 失效；文档漂移保留原请求回执，不能重发。完整枚举和事件处理使用协作式时间预算，不能中断单次阻塞 API。[恢复细节](SNAPSHOT-RECOVERY-FIX.zh-CN.md)
- 批量参数预览的实际生产 C# 在受控 peers 中 13/13；生产 MCP、原子队列、目录、字段及原回执合组 72/72。真实 Edge 在独立 HTTP/合成宿主上验证 `@`、负数参数 ID 文本输入与逐行结果，未接触 Revit。其真实 Codex 端到端和真实 Revit 查询未验。
- 项目绑定预览实际 C# 受控 peers 20/20；原子宿主合组 109/109，含原始队列缺少或关闭 atomicRead 时拒绝。合并后的预览、目录、MCP 和回执 Node 合组 106/106；真实 Edge 在独立合成面板验证 `@pppb`、两页和同一指纹。真实 Codex 与真实 Revit 均未验。
- 实际工作区 MCP 与聊天回执夹具复现了快照启动超时后缺少聊天核查凭据的问题，已接入现有原回执 owner；同一请求的迟到回执可核对并更新记录，未重发。成功状态同时提供结构化 MCP 结果；此为合成队列验证，不是真实 Revit 回执。
- 另行尝试真实 Codex app-server 连接工作区 MCP 并查询合成快照状态，等待 90 秒超时，未确认该轮结果；隔离测试未保留足够请求级证据，不能判断该次合成查询是否执行，也未自动重发。在另一独立合成文档中测试不同的 `start` 动作：Codex 读取了准确契约，生产 MCP 向合成队列发布一次 `6c168c41-50c9-41a2-93cf-c44a2450b9db`，但 120 秒内整轮未终结，未确认最终回复，也未重发。故快照的真实 Codex 端到端完成仍待验证；上述 21 项 Codex 合成操作的记录不包含快照。
- 未注册的删除回滚预览核心 10/10，删除准入原语 13/13、参数绑定准备 8/8，相关 JS 与未注册边界 11/11；它们不是可调用工具。结构柱/基础 C# peers 17/17。
- 完整 57 份 C# 候选使用本机 Revit 2024 API 和固定 WebView2 SDK 引用编译成功，DLL 仅位于本批新建隔离目录，未加载、安装或替换现有插件。独立构建摘要为 `a6994f910622ac2d626d3fe89177c8189995e7e443973ad8d0a03e3305a4243f`。

## 尚待验证

真实 Revit 模型中的创建效果、工作共享、族几何、尺寸稳定参照、级联行为、Revit 内嵌 WebView 与客户机安装均未验。当前模型和端口 41874 未操作；没有真实模型写入。未知结果必须核对原回执，不能重发原操作。

未有具名入口的 9 项为创建共享参数、创建项目参数、按筛选批量写参数、删除构件、删除图纸、DWG/IFC/NWC 导出与三维渲染。删除需要级联清单及可信逐次审批；批量筛选写需要完整影响和逐项原态；导出和渲染需要独立文件副作用及不覆盖发布 owner。上述缺口未用普通事务或路径前缀检查冒充完成。参数只读准备及删除预览/审批基础源码尚未注册；删除的共享队列可信发起缺口见 [删除审批 owner](DELETE-APPROVAL-OWNER.zh-CN.md)，参数绑定事实的范围见 [参数准备](PROJECT-PARAMETER-PREPARATION.zh-CN.md)。本地 AEC 源中共享参数和项目参数的创建 handler 也明确为未实现，不能直接从现有 handler 获得完整功能。

后续研究切片保存在私有仓库独立分支，未并入本候选的公开操作：`codex/aec-filter-research-20261107`（`6cf45b2`，原请求身份未证明时即使启用实验宏也拒绝执行）、`codex/aec-delete-research-20261107`（`996e3ae`，默认关闭的原生删除审阅和原回执原型）、`codex/aec-export-research-20261107`（`7496c57`，未注册的 DWG staging 租约和日志原型）及 `codex/aec-shared-parameter-research-20261107`（`a90f919`，独立共享定义文件与应用设置实验）。它们的受控测试和已知缺口分别记录在各分支；这些分支基于较早源码，不能作为当前候选安装或宣称生产可用。
