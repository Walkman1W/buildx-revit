# Project instance binding read-only preview

The named `revit_preview_project_parameter_binding` is a read-only atomic query; it does not grant authority, insert a binding, access a shared-parameter file, or change `SharedParametersFilename`. It is not an implementation of `revit_create_project_parameter`.

It accepts an exact GUID, existing document definition ID and data type, and 1–30 distinct top-level bindable category IDs. It rejects a bound definition, mismatched identity, existing instance parameters with that GUID, invalid/duplicate identities, or more than 500 affected instances. Every page first recaptures the complete current matching instance list; it returns at most 50 entries with the complete count and a fingerprint bound to the host session and all captured facts. Subsequent pages must supply the original fingerprint and are refused if impact or session changes. It notes that future instances would also be affected. The bounded collector fails rather than returning a partial list. A cooperative five-second budget is checked during category and instance enumeration and before returning; a single blocking Revit API call or enumeration step cannot be interrupted by this timer and may exceed that wall time. Revalidation re-reads the full set and rejects drift. Its document title and path are facts, not a secure host/session identity or user confirmation.

A future writer still needs a real per-action user decision showing the entire impact, document/session identity and a trustworthy original receipt/no-replay chain; a transaction must recapture the snapshot and verify the result after commit. Binding may have consequences beyond the enumerated existing instances. Whether a loaded-but-unbound InternalDefinition can be successfully inserted in a real Revit 2024 document is not established by compilation. Do not use this preview as authorization.

Autodesk describes `SharedParameterElement.GetDefinition()` as returning an `InternalDefinition`: [SharedParameterElement](https://help.autodesk.com/cloudhelp/2021/ENU/Revit-API/files/Revit_API_Developers_Guide/Basic_Interaction_with_Revit_Elements/Parameters/Shared_Parameters/Revit_API_Revit_API_Developers_Guide_Basic_Interaction_with_Revit_Elements_Parameters_Shared_Parameters_SharedParameterElement_html.html). The installed 2024 RevitAPI XML documents `BindingMap.Insert(Definition, Binding)`; its signature alone does not prove the requested runtime behavior.

Validation: compile the production preparation against the installed 2024 API in an isolated output directory, and execute `tools/check-project-instance-binding-preparation.ps1` against synthetic peers only. Neither is a live Revit, UI, permission, file, or model test.
