# 未注册 IFC staging 原型

Revit 2024 API 文档要求 IFC 导出时已有打开的事务；`FilterViewId` 使用所选视图的可见性设置，不保证输出只含该视图中的元素。原型限定 IFC4、一个当前文档视图、无基础工程量、无墙柱分层和零空间边界级别；其他隐藏导出器默认设置、插件及依赖仍可能影响结果。通过 `OptionalFunctionalityUtils.IsIFCAvailable()` 拒绝不可用环境，但真实插件行为未验证。

原型只调用内部租约，文件固定为 `model.ifc`；事务回滚状态单独记录，绝不声称磁盘文件被回滚。出口返回 false、抛错或观察失败均保留原有文件；多文件结果不允许发布。每次导出前要求注入原请求 started 日志，重复请求由日志 owner 拒绝。当前仅有受控日志替身，不具生产持久回执和崩溃恢复能力；没有超时中断或真实进程终止测试，超时不得重导，应核查原请求。

IFC 租约复用独占目录实验和身份/摘要观察，但枚举与检查存在并发窗口，完整清单不能证明；因此 `ManifestComplete` 和 `PublicationAuthorized` 恒为 false。没有可信用户目的地选择、逐次授权或发布链，不注册工具。受控 Revit 替身七项、隔离 NTFS 六项通过，Revit 2024 API 引用构建成功；未运行真实 Revit、IFC 导出器或用户目录。
