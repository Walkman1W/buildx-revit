# BuildX 访问权限

模型工作区在输入框下方分别提供“访问权限”和“执行方式”。

| 访问权限 | 范围 |
| --- | --- |
| 只读 | 可以读取本机资料和模型，拒绝文件及模型写入。 |
| 项目读写 | 在资料库添加目录，点击“设为读写工作区”，核对并确认目录；允许该目录及子目录中的文件和当前 Revit 项目编辑。 |
| 完全访问 | 核对并确认后，允许使用当前 Windows 账号可访问的本机路径，不要求逐个登记 RVT。不会获得管理员权限。 |

“添加资料”只提供参考内容；只有“设为读写工作区”会发起目录写入授权。选择会按 BuildX 账号保存在本机，可随时切回只读。账号切换会撤销当前宿主投影；下一账号读取自己的策略。模型适用范围在操作前重新核实。

| 执行方式 | 行为 |
| --- | --- |
| 回滚预览 | 执行事务后回滚，返回检查结果。 |
| 确认后应用 | 实际提交前显示本次操作供确认。 |
| 自动应用 | 已授权范围内，明确要求提交的普通操作直接执行。显式预览仍回滚。 |

需要连续建模时，选择“完全访问”，确认范围，再选择“自动应用”。普通 C#、保存命令和执行命令在这个组合下不再逐次弹确认；专用族生命周期和外部组件仍使用各自的审批能力。事务提交不等于保存 RVT，保存仍需明确操作。

## 文件能力

- `buildx_file_list`：本机目录分页；不递归，不跟随链接。
- `buildx_file_read`：读取不超过 1 MiB 的 UTF-8 文本，每页最多 8000 字符，返回 SHA-256 和完整性状态。
- `buildx_file_write`：新建或整体替换不超过 1 MiB 的 UTF-8 文本；替换必须携带刚读取的 SHA-256，原内容先备份，完成后读回核实。

访问范围和格式支持是两件事：完全访问允许本机路径，但通用文件工具目前只编辑 UTF-8 文本。RVT 使用 Revit API，PDF、Office 等二进制格式仍需对应工具。没有新增 shell、网络或任意进程执行能力。工具不能修改自己的授权策略、允许清单、安装记录或权限存储。

## Revit 加载与验证

新的统一模型授权需要宿主 0.8.0。旧宿主仍可提供只读查询，但不会接受新策略下的写入。更新 DLL 指向后需保存工作并重新启动 Revit；重启 BuildX 服务不能替换 Revit 已加载的 DLL。
