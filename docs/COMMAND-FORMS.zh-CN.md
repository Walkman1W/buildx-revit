# 命令表单与个人命令

全部命令在同一列表中展示，名称后用“系统”或“个人”小标签区分，不提供分类切换页。系统命令由固定工具契约收集参数、校验并直接执行，不经过模型推理。个人命令通过自然对话生成 C# 草稿，确认保存后按准确的不可变版本复用；保存与执行分开。

## 用户流程

- 系统 → 修改参数：在 Revit 选元素 → 读取当前选择 → 选元素并读取参数 → 选参数、填新值 → 加入修改 → 核对后预览或应用。
- 系统 → 移动/复制/创建：使用模型选择、标高及类型下拉；位置和位移用 X/Y/Z 数字框，长度以 mm 填写。可选的分页与技术参数收在“更多选项”。
- 个人：刷新本机保存列表 → 查看命令 → 使用这个命令 → 填必要输入 → 核对后预览或应用。
- 创建命令：新开空对话，保留原草稿，预填创建引导；用户自行描述和发送需求。Agent 沿用 `revit_save_command` 保存能力，不自动运行生成的脚本。

模型工作区只显示新版：页面初始化完成前，基础布局保持隐藏；组件或样式加载失败时显示加载和重新加载提示。基础 DOM 仍由新版、源码工作区及客户对话共用，不能直接删除。其他工作区不使用模型页面的启动保护。

## 控件职责

| 模块 | 职责 |
|---|---|
| `public/command-fields.mjs` | 文本、整数、小数、是/否、枚举、坐标和编号列表 |
| `public/command-choice-field.mjs` | 当前选择、标高、类型下拉及分页，保留来源模型 |
| `public/parameter-change-field.mjs` | 根据真实参数类型生成新值输入与修改列表 |
| `public/personal-command-fields.mjs` | 根据已读取版本的类型声明和中文标签生成个人表单 |
| `public/command-form-source.mjs` | 来源身份及安全整数编号的唯一前端解析边界 |

控件只产生意图与结构化值。`app.js` 持有请求、会话和草稿；服务器和工具继续拥有权限、当前模型绑定及执行。目录重建后，有来源的选择清空要求重读，不能降级为无来源 ID。

真实只读别名可能把 Int64 元素 ID 返回为十进制字符串。表单只把可精确表达的正整数转换为写入工具接受的 number；超范围编号显示限制并排除，不能取整。

修改参数首版支持文字、Int32 整数、YesNo，以及明确长度类型的 Double（mm 与内部英尺换算）。只读、ElementId 和未知数值单位不能靠参数名或显示文字猜测。执行带 `sourceDocument` 约束，服务器以新鲜状态核对宿主和模型；预览回滚，应用只保留内存修改，不保存模型。

## 个人命令输入约定

复用已有 `parameters` 类型映射，只支持 `string`、`number`、`integer`、`boolean`。可选 `parameter_labels` 为字段提供中文名称及必要单位：

```json
{
  "parameters": {"height_mm":"number", "enabled":"boolean"},
  "parameter_labels": {"height_mm":"高度（mm）", "enabled":"启用"}
}
```

标签是不可变版本的展示元数据，不改变源码、输入键名、单位或执行权限。旧版本没有标签时保留原名，不推测含义。已定义命令在再次运行时无需模型；任意 C# 自动推断输入、任意数值单位转换及可视化流程组合尚未实现。

## 验证范围

组件、真实 composer 和服务 HTTP 回归；真实 Edge 在隔离端口使用受控模型回执，验证原生控件、中文标签、新会话、原草稿、宽窄窗口和零模型调用。该验证不等同于真实 Revit WebView、实际 C# 生成质量或模型写入验收。正式服务加载需要遵循当前会话的重启授权。
