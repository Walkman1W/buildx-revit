# 隔离范围锁句柄实验

仅用于实验，未接入产品。实验复用 research-scope-owner 初始化的相邻 `.identity`，以 Windows 根句柄的卷序列号、文件 ID 和创建时间核对锚点中根身份，在操作前复查；锁文件通过根句柄相对创建。释放始终返回 unknown、保留锁。

自建临时目录 6/6：跨进程并发争锁；根句柄打开后替换根路径；启动前替换根、锚点缺失或损坏；操作前锚点损坏；正常退出及强制终止后保留锁；无可信回执时拒绝释放。

此实验不是生产安全边界：锚点仍按路径读取，没有 ACL 或防替换保护；检查与使用之间锚点可被替换，只核验锚点根字段而非四个子目录。未验证重解析点全链路、文件持久性和断电；没有可信原请求、同一宿主及终态原回执验证。相对操作在已打开的原根上，不保证其他进程能找到被移动的原根。禁止接入生产，项目参数门禁保持关闭。没有访问 Revit、41874 或模型。

队列读取独立探针 `QueueRead.cs`：先打开根及 inbox/outbox 目录句柄，再相对打开 host、原请求及回执文件，检查句柄对象类型、非重解析点、非零文件 ID 和文件单链接；限制大小并以严格 UTF-8 读取。在临时目录实测，持有这些句柄时根目录重命名被 Windows 拒绝，随后读取到三个原文件（1/1）。首次测试原假定可以移动根，实际得到 EPERM；测试已改为验证此实际行为。

该探针未接入现有 recovery owner，也未核对文件 ID 与预先捕获的可信身份；文件本身在打开前仍可被替换，内容尚未作原请求或回执语义校验。根与锚点、ACL 和断电保障仍未完成；不得启用 release。

新增受控合成夹具：发布前捕获 host/request 的句柄卷号、文件 ID、创建时间及 SHA-256；恢复时重新读取并比对，再核对合成回执的请求 ID、摘要、宿主 session 和终态。测试 2/2：覆盖相同内容但文件对象替换、内容篡改、宿主变化、错误请求 ID、错误宿主、非终态及缺失回执，均 unknown。队列读取仍为隔离探针；该合成回执并非 Revit 项目绑定业务契约，捕获记录仅存内存，读取期间文件写入竞态、可信配置根/ACL、真实原回执及断电均未解决；release 固定关闭。

新增仅供隔离测试的捕获子进程：将合成 host/request 身份与摘要独占写入文件并 fsync，子进程退出后由另一子进程读取并比较；一致时合成回执返回 committed，修改请求后 unknown，2/2。此夹具预先放置了合成回执，不模拟真实发布顺序；记录路径未受保护，未验证崩溃中断或断电，不等于持久恢复安全。

尚未将句柄读取结果接入 `interpretModelWriteReceipt` 的真实项目绑定解释器，也未验证准备 ID、文档、事务业务语义；不可释放锁。现有探针在读前打开所有文件，不能直接充当发布前无回执的捕获流程。生产配置根及 ACL 未验证，门禁继续关闭。

增加项目绑定隔离夹具：原生探针允许捕获时没有回执；独立捕获进程记录 host/request 后退出，测试随后写入模拟宿主回执，由另一个进程读取并交给现有 `interpretModelWriteReceipt`。错误准备 ID、文档标题及 committed 与 rollback 不符均为 unknown；匹配模拟回执返回 rolled_back。与原探针合组 4/4。测试只是将请求文件预放在 inbox，未模拟真实发布原子动作或强制终止；使用夹具自带 sourceDocument，没有验证可信记录、原始回执真实性或持有锁与队列同根。记录仍按路径保存、ACL 和断电均未验证；release 和生产门禁仍关闭。

新增统一根句柄隔离探针：单个进程打开一个配置根，以该句柄相对打开 queue/inbox/outbox 并创建 scope.lock；受控测试在句柄持有期间根目录重命名被拒绝，强杀进程后锁保留，同一路径重启争锁失败（1/1）。尚未把现有锚点身份验证接入该新探针，重启前替换根仍可绕过；不读取或校验回执，不释放锁。与生产 owner 无连接，ACL、断电和可信根仍未建立，门禁继续关闭。

统一根实验进一步读取既有 `.identity` 并与打开根句柄的卷号、文件 ID、创建时间对比；扩展测试在强杀后替换根目录，重新启动时拒绝该替代根，1/1。只在启动时检查锚点，锚点依然可被并发替换且没有 ACL；未接入发布证据和解释器，也没有任何释放实现。不可用于生产。

新增独立 C# 回执研究检查器，仅对 JSON 输入返回 candidate/unknown，不读文件也不释放锁。固定单类别、零时长的模拟成功夹具及请求 ID、文档、事务、准备 ID 四个失配案例与现有 Node 解释器结果一致（1 项测试、5 个案例）。这不是经证明等价的安全校验：日期解析、时序关系和完整 hostTimingFacts、参数契约、可信原请求来源等尚未完整复刻；candidate 仅表示通过该实验检查，不能授权释放。仅覆盖 rollback 样例，未验证 commit、失败回执和恶意输入的全空间。门禁继续关闭。

回执检查器续批收窄 UTC 格式和 unmatched 零时长时序字段；共享夹具新增 commit、rollback 两个正例及日期、宿主 session、时序缺失关联等反例，共 10 例一致，1 项测试通过。仍未完成完整参数契约、可信宿主来源、所有日期/数值边界及 Node 完整时序语义等价；C# 是受限研究检查，candidate 不可触发释放。

参数续批补充 GUID、正定义 ID、类别 ID、数据类型和 session 形态等收窄检查；四个非法参数与 Node 预览契约均拒绝。修正数值字段不能把字符串或布尔转成数字。共享测试也明确两个有意不等价例：Node 接受 matched 和合法非零时序，而 C# 当前返回 unknown。1 项测试通过。尚未对完整 recovery adapter（含持久原请求和宿主来源）做共享比较，参数契约也非完整；仍不可释放。

时序续批支持 matched/unmatched、非零验证和 dispatch 时间，检查数值非负有限、work 与 validation/dispatch 关系及可选时间字段一致性。此前两个 Node 接受而 C# 拒绝的共享样例现均接受；现有反例通过（1 项测试）。仍未完成完整 recovery adapter 端到端对照、可信 host/request 绑定和完整参数/日期边界，不能认定等价，不允许释放。

新增共享恢复 adapter 对照：使用真实 `captureRecovery` 捕获原请求并模拟发布，后续将相同原始数据交给 `recoverOriginal` 与 C# 研究检查器；1 项测试覆盖有效回滚、错误日期、回执宿主、准备 ID、宿主文件和请求字节篡改。原生侧比较 host/request 摘要由测试 JS 完成，不是 C# 持有句柄或生产接线；未比较所有文件身份/重解析点、ACL、参数及 crash 场景，不能声称端到端等价或授权释放。

新增独立进程反例：锁创建后强杀进程，替换整个根及相邻 `.identity` 并重新初始化，该实验会接受新根并再次创建锁；与只替换根被拒绝形成对照。两项测试 2/2。此结果证明未受信任的锚点无法提供跨重启防重：不能以此授权终态释放或开放生产入口。这里未实现安全集成；需要先建立并验证由可信主体持有的根和身份锚点、权限以及同句柄发布和原回执来源。无 Revit 或模型访问。

## 2026-11-07 默认关闭补丁

研究范围所有者及独立原生试验默认拒绝启动，只有显式设置 `BUILDX_UNSAFE_SCOPE_RESEARCH=1` 才能重现旧实验；该开关仅供隔离实验，不能用于产品。缺少可信根及锚点保护、ACL 核验、单句柄原请求与可信回执验证、原子事务及断电恢复。旧实验在根和锚点同时替换时可绕过，切勿将其视为修复。生产入口继续关闭。

在自建临时目录中验证缺省拒绝、目录和锚点替换、8 个并发独立进程，以及无锁文件副作用，`node --test research/scope-handle/default-closed.test.mjs` 1/1 通过。该测试仅证明默认关闭，不证明可信实现、安全释放、持久性或真实 Revit 验收。下一步需要设计受保护的安装时可信锚点与 ACL 验证，并在同一根句柄生命周期完成请求、回执、锁操作和故障恢复，完成对抗测试后才能讨论开放。

新增 `HeldTransaction.cs` 隔离探针：根目录句柄拒绝删除共享，以相对句柄持有单链接锁、原请求及模拟回执；请求摘要与模拟回执匹配时通过同一锁句柄标记删除。拒绝回执、第二进程争用、目录/锁替换、持有请求期间覆盖、强杀后锁保留和模拟成功释放在自建临时目录验证。默认关闭，只有研究开关启用。它不创建锁或持久发布原请求，也未验证业务回执真实性、ACL、可信根、断电和进程重启后根替换；故不构成完整安全事务或可接入接口。当前令牌为 medium integrity，管理员组 deny-only，无法凭此声称已配置独立受保护主体；未更改系统账户或 ACL。默认关闭与持有句柄探针合组 2/2。

项目参数句柄探针 `ProjectHeldTransaction.cs` 以独立进程 capture/recover：capture 在同一根句柄相对打开 host/request，记录二者文件身份与 SHA-256 至独占创建的锁文件并 Flush(true)；recover 相对打开并持有同一锁及原始 host/request/receipt 句柄，比较记录，再执行此前受限 C# 项目回执检查，匹配后在持有的锁句柄上标记删除。自建目录实测重复捕获、同内容替换请求文件、缺失回执、错误文档/模式结果/准备 ID 被拒绝，匹配模拟回执可释放；与前两项合组 3/3。

严格限制：回执检查器是现有 C# 研究检查的副本，**不是**完整 JS 生产解释器等价实现；没有可信授权范围/批准记录、真实宿主回执来源与项目发布协议，也不支持批量合同。捕获没有先验证审批或请求契约，异常中留下的空锁按 unknown 保留；文件 flush 不证明断电一致性。目录与锚点/锁记录可在进程退出后由同一用户替换，可信根和 ACL 未建立。所有程序只允许隔离研究开关启用，禁止业务接入和生产释放。
