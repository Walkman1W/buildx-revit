# 隔离范围锁句柄实验

仅用于实验，未接入产品。使用打开的根目录句柄，通过 NtCreateFile 相对创建固定锁文件。临时目录测试 4/4：两个进程并发争锁仅一个成功；持有根句柄时路径被替换，操作仍落在原目录；正常退出及强制终止后锁文件仍存在。因为尚无可信锚点和原回执，release 固定返回 unknown、保留锁，测试验证无法再次申请。

限制：每次进程启动独立按路径打开根，尚无受信任锚点或 ACL；启动前替换根可绕过锁。未实现可信原请求及同一宿主的终态回执校验、归档、文件类型或重解析点全链路、目录持久化或断电验证。现有 Node 回执验证器自身按路径检查后读取，也不能直接用于安全释放。禁止连接生产流程；项目参数开关保持关闭。没有访问 Revit、41874 或模型。
