# 隔离范围锁句柄实验

只用于实验，未接入产品。使用打开的根目录句柄，通过 NtCreateFile 相对创建固定锁文件，并通过打开的文件句柄删除。临时目录测试 4/4：两个进程并发争锁仅一个成功；持有根句柄时路径被替换，操作仍落在原目录；正常退出及强制终止后锁文件仍存在；显式释放后可重新申请。

限制：每次进程启动独立按路径打开根，尚无受信任锚点或 ACL；启动前替换根可绕过锁。release 不验证归属或原回执，不能用于实际恢复。没有保存请求、验证文件类型或重解析点全链路、归档、完成回执、目录持久化或断电验证。禁止连接生产流程；项目参数开关保持关闭。没有访问 Revit、41874 或模型。
