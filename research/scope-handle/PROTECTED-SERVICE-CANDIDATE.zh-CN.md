# 独立受保护 owner：本机隔离候选（未实现）

目的：给原请求和范围锁提供独立于普通客户端的持久 owner；当前无可运行服务，也没有授权安装。`ProtectedOwnerServiceCandidate.cs` 仅可编译成无条件退出的控制台骨架，不连接服务控制管理器（SCM），不能注册为服务。`protected-owner-contract.mjs` 仅为不可信数据的一致性模拟，不是服务程序。

## 候选交付与身份

- 构建目标：Windows x64，独立 `BuildX.ProtectedOwner.Service.exe` 和版本化清单；对依赖、摘要、签名及升级兼容性另行确定。此名称是设计目标，当前测试产生的是临时 `candidate.exe`。
- 服务身份：优先研究 Windows 虚拟服务账户 `NT SERVICE\BuildXProtectedOwner`；须在目标系统验证账户 SID 创建时机、令牌、权限及跨重启稳定性。该候选不创建本地用户、不要求密码。若平台不满足，重新设计并征得对应授权，不降级成当前交互用户。
- 数据候选根：`%ProgramData%\BuildX\ProtectedOwner\v1`，由受授权的安装器建立，分设 `anchor`、`requests`、`scopes`、`receipts` 和 `audit`；具体卷、容量、保留和备份策略在安装前核实。客户端提交标识与有限内容，不指定任意路径。请求原文可能含用户数据，安装与备份方案须明确保护和保留规则。
- 专用目录/文件 ACL 候选：服务 SID 和 SYSTEM 可访问；安装、修复由经明确授权的管理员执行；普通交互用户仅使用 IPC，不拥有数据目录、不得写入、重命名、删除或修改 DACL/所有权。验证继承、父目录删除子项、重解析点和权限撤销，不假设目录内 ACL 单独足够。Windows 管理员/SYSTEM 不在此边界的防护范围内。

## IPC 和事务

- 候选 IPC 为本机命名管道，拒绝远程客户端，设置管道 DACL 并核验经系统提供的客户端令牌、SID、会话和进程身份；服务端不接收客户端自报身份作为权威。管道名、允许的主体、宿主身份和重连机制需经威胁评审及实机测试。允许访问 IPC 不等于授权操作。
- 最小接口：`reserve` 接收由可信批准 owner 提供的一次性批准及不可变原请求，服务自行绑定批准范围、目标文档和宿主；`inspect` 以原请求 ID 返回有限状态；`settle` 只接收原请求 ID，服务自行从可信来源读取并用固定业务解释器校验原回执。所有权、撤权、重放、乱序与错误均失败关闭。批量需逐项核对，不能由客户端提交成功布尔值。
- 服务持有验证过的根和相关文件句柄，独占创建持久范围锁，发布前持久记录原请求身份、摘要和批准证据；同一锁句柄仅在可信终态确认后释放。安装锚点、ACL 验证、服务端请求发布、宿主回执写入及恢复需要完整协议，当前都未实现。无真实跨身份证据时返回 unknown，禁止自动重发或解锁。

## 授权后的安装、停止与回退草案

1. 先检查已有 BuildX 服务、目录、宿主及运行中请求，记录精确路径、ACL、配置和版本；备份已有状态，不覆盖未知服务。准备并审核二进制、完整清单、ACL 和回滚脚本。
2. 经覆盖具体操作的授权后，以管理员安装服务并配置专用身份、目录、ACL 与受限管道，再启动这个新服务；不重启现有服务或 Revit。逐项读取配置、令牌 SID、ACL 与进程身份，执行不同身份拒绝测试和故障恢复验证。
3. 出现问题时先停止接收新请求、保留 unknown 和所有原始锁/回执；确定无进行中事务后仅停止新服务。恢复此前服务配置、程序及 ACL 必须按安装前精确备份进行；不自动删除受保护数据。是否卸载新服务、删除新增目录和身份依赖均须按具体范围授权并检查影响。
4. 更新/回退需验证未完成事务和持久格式兼容性；强杀、异常、重启和断电不能被解释为事务已回滚。升级期间禁止重复发布原请求。

## 当前验证

离线测试只编译 `ProtectedOwnerServiceCandidate.cs` 并运行四种参数，均退出 6。没有 SCM 集成、管道、真实身份、目录 ACL、服务构建、安装、启动或 Revit 交互；该骨架不能作为产品服务交付。依赖真实 Windows 服务身份与客户机的安全测试仍未执行。

## 2026-11-07 离线服务骨架

`ProtectedOwnerService.cs` 可独立编译为引用 `ServiceBase` 的 Windows 可执行文件，包含命名管道名称与返回 `NamedPipeServerStream` 的关闭工厂。`OnStart` 和管道工厂均直接拒绝；没有创建管道或监听，不能作为服务安装使用。内存协议识别版本 1 的 status（unavailable）、reserve/settle/inspect（denied），限制 UTF-8、长度、字段和操作；不接收或声称识别任何模拟身份。`ServiceProtocolFixture.cs` 在内存验证正常及非法报文，`service-protocol.test.mjs` 在临时目录分别编译服务入口和测试入口，1/1 通过；不启动服务或管道。

部署前仍需完成并验证：系统服务身份和 SCM 生命周期、专属数据根与跨重启身份锚点、父链和文件 ACL、受限命名管道创建和远程拒绝、操作系统客户端身份鉴别及授权、规范化协议与重复 JSON 字段拒绝、持久批准与原请求发布、固定项目/批量回执解释器、锁和恢复事务、日志和隐私、升级回退、崩溃/断电及跨身份对抗测试。当前协议只是离线分发草图，JSON 解析器的重复字段行为尚未收口，不能接入 IPC。没有安装/启动服务或改系统权限。
