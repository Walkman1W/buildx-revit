# 有界参数柜族：源码与验证边界

本构建器面向独立的常规模型族文档，输入宽 `300–5000`、深 `150–2500`、高 `300–5000`、板厚 `6–80` 毫米及 `0–8` 块层板。默认尺寸为 `1200 × 600 × 2200 mm`、板厚 `18 mm`、3 块层板；还会校验柜内空间、门缝、单板几何及 Revit 当前短曲线容差。门缝固定为 `2 mm`。这里是本地功能资源边界，不是家具设计或制造认证。

族作业使用独立的 `host + template SHA-256` 绑定，不伪造项目句柄。创建属于临时族文档，由现有作业 registry 和原生事务 owner 保有；失败时保留作业和真实回滚/未知状态。构建尝试用原生参照平面、尺寸标签和拉伸参数约束左右侧板、顶底板、背板、双门与层板，并执行 A→B→A 类型切换、重生成、逐板包围盒和实体体积回读；任意校验失败不得提交事务。

独立保存通过 `family_save_cabinet` 产生内部自有 artifacts 下的新 RFA，不覆盖现有文件；关闭、哈希、独立重开、当前类型/参数/几何和最终哈希都有独立的结果。当前不接受任意指定保存目录。未保存柜体必须经单独授权的 `family_close_cabinet` 关闭，关闭会放弃未保存内容；既有 `family_close_job` 明确拒绝柜体。既有 `family_save_job` 只处理阀门，既有 `family_load_job` 明确拒绝柜体，因为这些旧接口未提供柜体所要求的逐次人类审批。柜体加载项目、项目冲突处理和放置实例尚未开放，不得经旧接口绕过。

构建器只提供无把手、铰链、开门动画、材质或制造细节的简单矩形柜；未验证的模板引用、维度绑定、API 行为会使请求失败并保留可核对的作业，而不是退化为静态几何并报告参数化成功。

## 验证

`family-core/tests/run-cabinet-planning.ps1` 使用实际生产 planner 做独立内存几何、范围、碰撞与 A→B→A 计算测试；`run-family-planning.ps1` 测试独立绑定及不可借用项目身份；`compile-revit-workflow.ps1` 使用已有 Revit 2024 API 做隔离编译。

这些检查**不能证明在真实 Revit 的实际模板中参照平面、尺寸标签和草图约束可用**。首次生产接入仍须在明确授权的独立族文档中执行并验证 A→B→A、保存、独立重开、关闭及取消/未知回执；不得触碰现有项目或声称验证了任意项目加载。外围 UI/MCP 必须在每次创建或保存前提供可核验的人类授权；在此机制未接通前，新操作不得向 Codex 可执行工具开放。
